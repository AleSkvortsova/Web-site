# Проекты Александры Скворцовой

Этот документ содержит краткое описание проектов, размещённых на сайте Александры. Проекты учебные и практические: они показывают путь освоения ИИ-инструментов и попытку применять их к реальным бизнес-задачам.

## RAG-ассистент для работы с документами

**URL на сайте:** `/projects/rag-assistant-for-documents`  
**GitHub:** `https://github.com/AleSkvortsova/RAG-assistant`  
**Направление:** ИИ и документы

RAG-ассистент — проект, в котором система отвечает на вопросы по загруженным документам. Ассистент умеет работать с `.docx` и `.txt` файлами, разбивать документы на чанки, сохранять их в ChromaDB и находить подходящие фрагменты по смыслу и ключевым словам.

В проекте используются:

- Python;
- OpenAI API;
- LangChain;
- ChromaDB;
- RAG;
- DOCX/TXT;
- JSON-cache;
- Telegram Bot API;
- server deploy;
- RAGAS;
- GitHub.

Важная часть проекта — деплой на сервер. Александра столкнулась с реальными техническими задачами: SSH, установка Python, зависимости, ограничения маленького сервера, переход с локальных embeddings на OpenAI embeddings, проблема со старым SQLite, pysqlite3-binary, неподдерживаемый регион для OpenAI API, автозапуск и проверка работы после перезагрузки сервера.

Главный результат проекта — не только бот, который отвечает по документам, а снижение страха перед технической частью: сервером, терминалом, зависимостями и деплоем.

## Дообучение стиля общения модели

**URL на сайте:** `/projects/noble-style-lora-rugpt3`  
**GitHub:** `https://github.com/AleSkvortsova/Noble-style-lora-rugpt3`  
**Направление:** Эксперимент с моделью

Проект посвящён дообучению языковой модели в заданном стиле с помощью LoRA. Александра решила проверить, можно ли немного изменить стиль генерации модели: сделать так, чтобы она отвечала в иронично-аристократичной манере с обращениями “сударь”, “сударыня”, “извольте”, “благодарствую”.

В проекте используются:

- Python;
- Hugging Face Transformers;
- PyTorch;
- LoRA;
- PEFT;
- RuGPT-3;
- локальный запуск;
- GitHub.

В качестве базовой модели использовалась небольшая русскоязычная модель `rugpt3small` от Sberbank AI, построенная на архитектуре GPT-2. По современным меркам это слабая модель, но она подошла для учебного эксперимента, потому что её можно было установить и обучить на обычном компьютере.

Вывод проекта: дообучение — это не кнопка “сделать хорошо”. Результат зависит от базовой модели, качества датасета и способа проверки. LoRA может немного сместить стиль генерации, но слабая модель и небольшой датасет не превращают её в качественного ассистента.

## HR-Copilot для подготовки к собеседованиям

**URL на сайте:** `/projects/hr-copilot`  
**GitHub:** `https://github.com/AleSkvortsova/HR-Copilot`  
**Направление:** ИИ-ассистент

HR-Copilot — проект AI-ассистента для подготовки к собеседованиям. Идея проекта — помочь человеку структурировать опыт, подготовить ответы на вопросы, разобрать вакансию и увереннее пройти интервью.

В проекте используются:

- Python;
- Flask;
- OpenAI API;
- GPT-4o-mini;
- HTML;
- CSS;
- локальный web service;
- prompt scenarios.

Этот проект ближе к прикладному сервису: у него есть web-интерфейс, сценарии взаимодействия и понятная пользовательская задача.

## ИИ-аналитик отчетов

**URL на сайте:** `/projects/ai-report-analyst`  
**Направление:** ИИ и аналитика

ИИ-аналитик отчетов — проект, где AI-агент анализирует данные отчёта и делает краткие управленческие выводы. В эксперименте использовался CSV-ввод, агентная логика, калькулятор и генерация аналитического резюме.

В проекте используются:

- Langflow;
- OpenAI API;
- AI Agent;
- Calculator Tool;
- CSV;
- n8n;
- HTTP Request;
- Docker local;
- JSON.

Проект показывает, как можно связать AI-агента с инструментами и автоматизацией. Агент не просто пишет красивый текст, а использует расчеты и данные.

## Интеграция ИИ-агента в n8n через Langflow

**URL на сайте:** `/projects/n8n-langflow-agent-integration`  
**Направление:** ИИ-автоматизация

Этот проект показывает, как связать AI-агента из Langflow с автоматизацией в n8n через HTTP Request. Идея — превратить отдельного агента в часть бизнес-процесса: передать ему данные, получить ответ и использовать результат дальше в сценарии автоматизации.

В проекте используются:

- n8n;
- Langflow;
- OpenAI API;
- HTTP Request;
- Docker;
- JSON;
- CSV;
- API key.

Проект важен как шаг от “агент работает отдельно” к “агент становится частью процесса”.

## Общая логика проектов

Все проекты на сайте объединяет практический подход:

- не просто поговорить с нейросетью;
- не просто написать красивый промпт;
- собрать работающую цепочку;
- проверить, где возникает техническая сложность;
- понять ограничения;
- честно описать результат.

Проекты пока учебные, но они демонстрируют развитие компетенций Александры в применении ИИ к бизнес-процессам.
